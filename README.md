# Nivi - AI Goal Negotiator

## Deploy to Vercel

1. Push this repo to GitHub
2. Import on vercel.com
3. Add environment variable: OPENROUTER_API_KEY = your key from openrouter.ai
4. Deploy

## Run locally

```bash
npm install -g vercel
echo 'OPENROUTER_API_KEY=your_key_here' > .env.local
vercel dev
```
